# CombatSolver 0.50.2

## 简体中文

- 单人智能药水会更完整地权衡省血收益与药水价值，减少为了很小收益消耗多瓶药水的情况，并保留必要保命、强制使用和战后补充药水的抵扣。
- 感谢 [shun-tong](https://github.com/shun-tong) 提交的 [PR #213](https://github.com/Torch1230/CombatSolver/pull/213)：改善单人长战斗中能力牌和药水的使用路线，强制用药后也能从仍可行动的回合继续寻找更好的路线。
- 感谢 [shun-tong](https://github.com/shun-tong) 提交的 [PR #227](https://github.com/Torch1230/CombatSolver/pull/227)：改善单人破除敌方格挡后的收尾、弃牌后继续进攻及延迟伤害路线的选择。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #230](https://github.com/Torch1230/CombatSolver/pull/230)：单人智能药水在主搜索用完时间后，仍可追加一次短时间比较，减少漏掉更合适用药路线的情况；符合条件时，计算会比原时间上限略长。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #229](https://github.com/Torch1230/CombatSolver/pull/229)：在支持的游戏环境和战斗中，单人继续优化路线时会利用已找到的获胜方案减少重复计算。
- 感谢 [tianyilt](https://github.com/tianyilt) 提交的 [PR #224](https://github.com/Torch1230/CombatSolver/pull/224)：提高改变手牌上限后的路线复用准确性。本 fork 同步适配多人各自不同的手牌上限，重算时会分别识别本机和队友的变化。
- 感谢 [link20031019](https://github.com/link20031019) 提交的 [PR #226](https://github.com/Torch1230/CombatSolver/pull/226)：Ctrl+F9 隐藏面板后，界面刷新和进入下一场战斗会保持隐藏，再次按键恢复显示；重启游戏后恢复默认显示状态。

本版合入官方 0.50.1 及其后续主线更新。多人继续提供手动请求的本机建议，最多推演十四个敌方行动周期，不预测队友主动操作；上述单人选路优化不改变多人贡献规则。

## English

- Single-player Smart potion decisions now weigh HP savings against potion value more consistently, reducing cases that spend several potions for a small benefit while preserving necessary survival uses, Force directives, and replacement credit for post-combat potion rewards.
- [PR #213](https://github.com/Torch1230/CombatSolver/pull/213) by [shun-tong](https://github.com/shun-tong): Improved single-player routes involving powers and potions in long battles. Searches can continue from playable turn boundaries after forced potion use to find better routes.
- [PR #227](https://github.com/Torch1230/CombatSolver/pull/227) by [shun-tong](https://github.com/shun-tong): Improved single-player choices for finishing enemies after breaking Block, continuing attacks after discarding, and winning through delayed damage.
- [PR #230](https://github.com/Torch1230/CombatSolver/pull/230) by [s1f102500012](https://github.com/s1f102500012): Single-player Smart potion decisions can run one short additional comparison after the main search runs out of time, reducing missed potion routes. When eligible, calculation can take slightly longer than the original time limit.
- [PR #229](https://github.com/Torch1230/CombatSolver/pull/229) by [ltlly](https://github.com/ltlly): In supported game environments and battles, continued single-player optimization uses already discovered winning routes to reduce repeated work.
- [PR #224](https://github.com/Torch1230/CombatSolver/pull/224) by [tianyilt](https://github.com/tianyilt): Improved route reuse accuracy after changes to the hand-size limit. This fork also supports separate multiplayer hand limits, recognizing changes for the local player and teammates when recalculating.
- [PR #226](https://github.com/Torch1230/CombatSolver/pull/226) by [link20031019](https://github.com/link20031019): Panels hidden with Ctrl+F9 stay hidden across UI refreshes and subsequent battles. Press the shortcut again to show them; restarting the game restores default visibility.

This release integrates upstream 0.50.1 and subsequent mainline changes. Multiplayer retains manually requested local-player advice, up to fourteen enemy action cycles, and no prediction of teammates' active actions. The single-player route improvements above do not change multiplayer contribution rules.
