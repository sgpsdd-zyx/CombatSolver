# CombatSolver 0.43.3（fork，本地准备版）

## 简体中文

- 修复多人建议中的遗物提示归属：明确标注「自己」或「队友编号」，避免把队友的佩尔之眼等效果看成本机收益。
- 修复不同玩家同时触发同名遗物时，提示被合并成一条的问题。
- 修复多人佩尔之眼的额外回合判断：未参加队友额外回合的玩家不会被误判为可以触发；其他效果给予额外回合时，也按游戏规则消耗该玩家自己的佩尔之眼。

沿用 0.43.2 的十四个敌方周期规划和普通多人计算双倍额度；单人沿用官方 0.43.0 路径。此包供本地试用，尚未创建新标签或发布 GitHub Release；真实联机尚未验收。

## English

- Multiplayer relic notes now identify you or the numbered teammate who owns the relic, so a teammate's Pael's Eye and other effects no longer appear to belong to you.
- Identical relic effects triggered by different players remain separate in the route notes.
- Corrected multiplayer Pael's Eye state: sitting out a teammate's extra turn no longer leaves the relic eligible to trigger. An extra turn granted by another effect also consumes that player's own Pael's Eye, matching the game.

Retains 0.43.2's fourteen-enemy-turn horizon and doubled ordinary multiplayer search limits. Single-player keeps the upstream 0.43.0 path. This is a local test package; no new tag or GitHub Release has been published. Live multiplayer remains unverified.
