# CombatSolver 0.43.2 (fork, local preparation)

## 简体中文

- 多人军师最多推演十四个敌方周期，帮助比较高血量长战斗中的持续输出和后期收益。
- 普通多人计算使用性能设置中时间和节点上限的两倍，并为后续周期保留计算机会。例如默认中档最多计算 240 秒；找到结果可能更早结束，也可手动停止。单人设置与行为保持不变。
- 详情显示本次多人计算的实际时间和节点上限；继续分别显示实际推演深度、规划上限和选路比较范围。

每个敌方周期 3 HP 本机扣血目标、手动计算和手动操作保持原样。十四周期是上限，预算不足或等待队友选择时仍会提前返回。预测继续假设队友不再主动出牌或用药，不能保证每场伤害更高或得到全局最优解。

此版仅准备本地试用包，尚未创建新标签或上传 GitHub Release。真实联机与可见游戏性能尚未验收。

## English

- Multiplayer advice can look ahead through fourteen enemy cycles, helping compare sustained damage and delayed benefits in long fights against high-HP enemies.
- Ordinary multiplayer searches use twice the time and node limits in the performance settings and reserve work for later cycles. The default Medium preset allows up to 240 seconds; searches can finish earlier or be stopped manually. Single-player settings and behavior are unchanged.
- Details show the effective multiplayer time and node limits. Actual forecast depth, the horizon limit and the comparison range remain separate.

The local target of 3 HP lost per enemy cycle, manual calculation and manual play remain unchanged. Fourteen cycles is a limit, not guaranteed coverage: budget exhaustion or a required teammate choice can stop the forecast earlier. Advice still assumes teammates take no further active card or potion actions and does not guarantee higher damage in every fight or a globally optimal result.

This version is prepared locally for testing. No new tag or GitHub Release has been published. Live multiplayer and visible-game performance remain unverified.
