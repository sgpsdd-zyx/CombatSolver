# CombatSolver 0.49.4

## 简体中文

相对于 0.49.3 的更新：

- 优化问题反馈提示：手动操作导致计算结果过期，以及战斗涉及第三方内容 Mod 时，不再提示上传问题包。
- 感谢 [fdkgf](https://github.com/fdkgf) 提交的 [PR #215](https://github.com/Torch1230/CombatSolver/pull/215)：优化战斗路线计算，找到胜利路线后减少重复搜索，缩短部分战斗的计算等待。同等战损和资源收益下，可能保留回合数较多的胜利路线。
- 感谢 [bingyang1132](https://github.com/bingyang1132) 提交的 [PR #217](https://github.com/Torch1230/CombatSolver/pull/217)：完善内容 Mod 的适配支持，让适配器能够处理额外回合、战斗中新获得的状态效果，以及修改过招式的原版怪物。需要配套更新对应的适配器。

## English

Changes since 0.49.3:

- Improved report prompts: outdated results caused by manual input and combats involving third-party content mods no longer prompt players to upload a report.
- [PR #215](https://github.com/Torch1230/CombatSolver/pull/215) by [fdkgf](https://github.com/fdkgf): Improved combat route calculation. After finding a winning route, the solver does less repeated searching, reducing calculation time in some battles. With equal HP loss and resource rewards, it may keep a winning route that takes more turns.
- [PR #217](https://github.com/Torch1230/CombatSolver/pull/217) by [bingyang1132](https://github.com/bingyang1132): Expanded support for content mod adapters to handle extra turns, newly gained status effects in combat, and vanilla monsters with modified move sets. Requires a corresponding adapter update.
