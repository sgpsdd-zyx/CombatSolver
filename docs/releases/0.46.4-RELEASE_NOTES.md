# CombatSolver 0.46.4

## 简体中文

- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #133](https://github.com/Torch1230/CombatSolver/pull/133)：新增默认开启的“多核内存回收”，首次加载后重启游戏即可生效，macOS 也支持普通启动。设置页分别显示当前状态与下次启动配置，可关闭并恢复原设置；开启或关闭都需要重启。该设置影响整个游戏，卸载或禁用 Mod 前请先关闭；实际内存和速度变化取决于硬件、战斗与其他 Mod。
- 感谢 [AuroraAeon](https://github.com/AuroraAeon) 提交的 [PR #134](https://github.com/Torch1230/CombatSolver/pull/134)：减少单人复杂战斗搜索中的重复试算。部分局面的推荐路线可能随之变化，搜索仍在所设预算内比较路线。
- 搜索进行中显示当前计算速度，完成后显示平均速度，便于了解计算进展。精简搜索顶栏的重复提示，同时保留路线是否完成验证和多人建议过期的状态信息。

多人继续为手动军师试用：仅推荐本人的操作，最多推演十四个敌方回合，不预测队友后续主动出牌或用药；真实联机尚未完成验收。

## English

- [PR #133](https://github.com/Torch1230/CombatSolver/pull/133) by [ltlly](https://github.com/ltlly): Added multicore memory cleanup, enabled by default and active after restarting the game once. Normal launches on macOS are supported too. Settings show the current mode separately from the next launch configuration and let you restore the original setting. Both enabling and disabling require a restart. This affects the whole game; turn it off before uninstalling or disabling the mod. Memory use and speed depend on hardware, combat, and other mods.
- [PR #134](https://github.com/Torch1230/CombatSolver/pull/134) by [AuroraAeon](https://github.com/AuroraAeon): Reduced repeated calculations during complex single-player searches. Recommendations can change in some situations; routes are still compared within the configured search budget.
- The search header shows the current calculation rate while searching and the average rate when finished. Removed repeated header notices while retaining route verification and stale multiplayer advice indicators.

Multiplayer remains an experimental manual advisor: it recommends only your actions, looks ahead up to fourteen enemy turns, and does not predict teammates' future active card or potion use. Live multiplayer validation is still pending.
