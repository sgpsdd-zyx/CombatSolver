# CombatSolver 0.43.4（fork，本地准备版）

## 简体中文

- 改进多人长线选路：暂时无法击杀时，已保留的不同本回合方案都有更深推演结果，就统一比较更远周期的输出，让需要数回合回本的铺垫有机会胜出。
- 继续优先控制已知死亡、救命资源和超额扣血风险；缺少完整后续、等待队友选择或计算余量不足时，保留原有建议。
- 不为选路增加新一轮搜索；仍最多推演十四个敌方周期，沿用普通多人计算双倍额度、每周期 3 HP 目标和手动操作方式。

长线收益可能以少量早期伤害为代价，队友行动也会改变后续局面；建议不保证十四周期全局最优或始终安全。保留 0.43.3 的遗物归属与佩尔之眼修复，单人沿用官方 0.43.0 路径。此包供本地试用，尚未创建新标签或发布 GitHub Release，真实联机尚未验收。

## English

- Improved multiplayer planning when a kill is out of reach: when each retained complete current-turn plan has a deeper simulated continuation, compare their damage at the same later enemy turn. Setups that take several turns to pay off can now win that comparison.
- Known deaths, death-save use and excess HP loss remain priorities. Keep the previous selection when continuations are incomplete, a teammate must choose, or too little computation time remains.
- Selection adds no new search pass. The fourteen-enemy-turn limit, doubled ordinary multiplayer computation limits, 3 HP target per enemy turn and manual controls remain in place.

Long-term gains can cost early damage, and teammate actions can change the outcome. Advice does not guarantee a globally optimal or safe fourteen-turn plan. Retains 0.43.3's relic ownership and Pael's Eye fixes; single-player keeps the upstream 0.43.0 path. This is a local test package with no new tag or GitHub Release. Live multiplayer remains unverified.
