# CombatSolver 0.48.0

## 简体中文

相对于 0.47.3 的更新：

- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #188](https://github.com/Torch1230/CombatSolver/pull/188)、[PR #199](https://github.com/Torch1230/CombatSolver/pull/199) 和 [PR #200](https://github.com/Torch1230/CombatSolver/pull/200)：优化复杂战斗的路线计算，减少重复模拟和对低价值路线的反复探索，改善故障机器人对感染棱柱、储君和铁甲战士对残杀千足虫等场景的计算时间。具体收益取决于牌组、场面和搜索设置。
- 将基于已知回血来源的路线剪枝推广到五个角色和所有原版怪物。减少对缺少可靠回血来源的高战损路线的反复计算，后续搜索也会利用已找到的胜利路线减少重复尝试。保留已有再生、实际持有的回血药水、战后回血、明确的卡牌与遗物回血，以及成长和保命目标；修书小刀仅在持有时计入。忽略炼制药水尚未产生的随机回血，药水实际效果保持原样。
- 感谢 [ACGNnsj](https://github.com/ACGNnsj) 提交的 [PR #190](https://github.com/Torch1230/CombatSolver/pull/190)：减少早期回合探索中的重复尝试，达到已设置的可接受战损目标时及时停止追加探索，并继续按既有规则考虑成长、遗物和用药目标。
- 感谢 [ACGNnsj](https://github.com/ACGNnsj) 提交的 [PR #190](https://github.com/Torch1230/CombatSolver/pull/190)：在“问题反馈”设置中新增“保留本进程全部战斗日志”。默认关闭，开启后从下一场战斗开始保留此前战斗的详细日志，方便分析同次游戏中的多场战斗；会增加磁盘占用，已清理的日志无法恢复。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #194](https://github.com/Torch1230/CombatSolver/pull/194)：修复部分带余像的路线在调整出牌顺序时，因攻击目标变化而中断计算的问题。调整后的路线无法执行时，保留原可用路线。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #194](https://github.com/Torch1230/CombatSolver/pull/194)：跑局统计文件损坏或统计处理异常时，停止本次统计，战斗路线执行仍可继续；不完整记录会明确标记，避免当作完整跑局上传。
- 感谢 [fengzhenhong](https://github.com/fengzhenhong) 提交的 [PR #197](https://github.com/Torch1230/CombatSolver/pull/197)：修正充能球数值预测，以及回合结束时临时力量、敏捷和集中效果的处理顺序，减少预测与实战结果的偏差。
- 感谢 [yM7-1](https://github.com/yM7-1) 提交的 [PR #198](https://github.com/Torch1230/CombatSolver/pull/198) 和 [PR #201](https://github.com/Torch1230/CombatSolver/pull/201)：修复原版地精死亡后召唤新敌人时，目标名称处理异常导致路线计算中断的问题；修复智能药水在部分开局路线中因用药状态识别错误而中断计算的问题，并减少单人预测中与部分第三方模组的调用冲突。

## English

Changes since 0.47.3:

- [PR #188](https://github.com/Torch1230/CombatSolver/pull/188), [PR #199](https://github.com/Torch1230/CombatSolver/pull/199) and [PR #200](https://github.com/Torch1230/CombatSolver/pull/200) by [ltlly](https://github.com/ltlly): Improved route calculation in complex fights by reducing repeated simulation and exploration of low-value routes. This improves calculation times in encounters such as Defect against Infested Prism, and Regent or Ironclad against the Decimillipede. Gains depend on the deck, combat state and search settings.
- Extended route pruning based on known healing sources to all five characters and all vanilla enemies. The solver spends less work on high-HP-loss routes with little reliable healing, and later searches also use wins already found to reduce repeated exploration. Existing Regen, held healing potions, post-combat healing, known card and relic healing, growth goals and survival resources remain accounted for. Book Repair Knife is considered only when held. Potential random healing from Alchemize is ignored until generated; actual potion effects are unchanged.
- [PR #190](https://github.com/Torch1230/CombatSolver/pull/190) by [ACGNnsj](https://github.com/ACGNnsj): Reduced repeated attempts during early-turn exploration. Additional exploration stops when the configured acceptable HP-loss target is met, while growth, relic and potion goals retain their existing rules.
- [PR #190](https://github.com/Torch1230/CombatSolver/pull/190) by [ACGNnsj](https://github.com/ACGNnsj): Added “Keep all combat logs this game session” to the Bug Reports settings. It is off by default and takes effect from the next fight, retaining earlier detailed combat logs for analysis across fights in the same session. This uses more disk space; deleted logs cannot be recovered.
- [PR #194](https://github.com/Torch1230/CombatSolver/pull/194) by [s1f102500012](https://github.com/s1f102500012): Fixed route calculation failures when reordering plays involving Afterimage changed the available attack targets. The original usable route is retained when the adjusted route cannot be executed.
- [PR #194](https://github.com/Torch1230/CombatSolver/pull/194) by [s1f102500012](https://github.com/s1f102500012): Corrupt run-statistics files or statistics-processing failures now stop statistics collection for that run while allowing combat route execution to continue. Incomplete records are explicitly marked to prevent uploading them as complete runs.
- [PR #197](https://github.com/Torch1230/CombatSolver/pull/197) by [fengzhenhong](https://github.com/fengzhenhong): Corrected Orb value predictions and the processing order of temporary Strength, Dexterity and Focus effects at turn end, reducing differences between predicted and actual combat results.
- [PR #198](https://github.com/Torch1230/CombatSolver/pull/198) and [PR #201](https://github.com/Torch1230/CombatSolver/pull/201) by [yM7-1](https://github.com/yM7-1): Fixed route calculation failures caused by target-name handling when vanilla Gremlins summon new enemies on death, fixed Smart potion calculation failures caused by incorrect potion-use classification in some opening routes, and reduced some call conflicts with third-party mods during single-player prediction.
