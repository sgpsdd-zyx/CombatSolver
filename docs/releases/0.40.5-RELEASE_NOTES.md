# CombatSolver 0.40.5 - 多人输出策略 / Multiplayer Offense

## 简体中文

这是 `sgpsdd-zyx/CombatSolver` fork 的本地准备版本。

- 多人军师以每回合扣血不超过 3 HP 为目标，在此范围内优先击杀和打出更多伤害，减少为了完全不掉血而一直防御的建议。
- 仍优先规避致命伤害；输出相同时选择扣血更少的路线。无法满足 3 HP 目标时，优先减少超额扣血，并显示实际预测值。
- 本回合已经付出的扣血会计入目标，治疗、重新计算和额外玩家回合都不会重置额度；未使用的额度不会累积到后续回合。
- 面板显示单回合扣血目标和当前预测中的最高单回合扣血，便于判断是否采用建议。

多人继续只建议本人的出牌和用药，最多推演七个敌方回合。你决定何时重算并自行操作；未来推演仍假设队友不再主动出牌或用药。单人策略沿用原有逻辑。真实联机和可见界面尚未完成全面验收。

### 安装与升级

1. 使用《杀戮尖塔 2》`0.111.0`，单独安装并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` 或更高版本。
2. 退出游戏，将 **CombatSolver-0.40.5.zip** 的内容解压到游戏的 `mods/CombatSolver/` 目录并替换旧版；DLL 与 JSON 应直接位于该目录，无需编译。
3. 只启用一份 Combat Solver，重启游戏后进入多人战斗，等待发牌与回合开始选择完成，再点击「开始计算」。

本地准备包位于 `releases/CombatSolver-0.40.5.zip`。安装包包含 Mod、Windows 辅助程序及许可文件，不包含 RitsuLib；非 Windows 系统无需运行 `CombatSolver.MemoryCleaner.exe`。

## English

This is a locally prepared version of the `sgpsdd-zyx/CombatSolver` fork.

- Multiplayer advice aims to lose no more than 3 HP per turn, prioritizing kills and greater damage within that target. It is less likely to keep defending solely to avoid all HP loss.
- Avoiding lethal damage still takes priority. Routes with equal damage prefer less HP loss. When the 3 HP target cannot be met, advice favors less excess loss and shows the actual forecast.
- HP already lost this turn counts toward the target. Healing, recalculating and extra player turns do not reset it, and unused allowance does not carry into later turns.
- The panel shows the HP loss target and the highest forecast loss in a single turn so you can decide whether to follow the advice.

Multiplayer continues to advise only your own cards and potions, looking ahead up to seven enemy turns. You decide when to recalculate and carry out actions yourself. The forecast still assumes teammates take no further active card or potion actions. Single-player keeps its existing strategy. Live multiplayer and the visible interface have not undergone full validation.

### Install or Upgrade

1. Use Slay the Spire 2 `0.111.0` and separately install and enable [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` or later.
2. Exit the game and extract **CombatSolver-0.40.5.zip** into the game's `mods/CombatSolver/` folder, replacing the old version. The DLL and JSON must sit directly in that folder. No compilation is needed.
3. Enable only one Combat Solver copy. Restart the game, enter multiplayer combat, finish the opening draw and turn-start choices, then click **Calculate**.

The locally prepared package is at `releases/CombatSolver-0.40.5.zip`. It includes the mod, its Windows helper and license files. RitsuLib is not bundled. Other systems do not need to run `CombatSolver.MemoryCleaner.exe`.
