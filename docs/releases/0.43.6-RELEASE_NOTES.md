# CombatSolver 0.43.6（fork，本地准备版）

## 简体中文

- 修复多人局队友死亡后仍保留部分能力时，点击「重新计算」报错的问题。
- 修正死亡队友的效果判断：停用期间不再触发佩尔之眼额外回合或继续结算残留能力；复活后按游戏规则恢复生效，救命效果仍可正常触发。
- 修正多人同时拥有奥斯蒂时，死亡队友的奥斯蒂最大生命被错误计算为零的问题。

沿用十四个敌方周期规划、每周期3HP扣血目标和普通多人计算双倍额度；单人沿用官方0.43.2路径。这是本地补丁包，尚未发布GitHub Release；已完成离线原生流程对照，真实联机尚未验收。

## English

- Fixed recalculation errors when a dead teammate still retains some powers in multiplayer.
- Inactive teammates no longer trigger Pael's Eye extra turns or keep processing retained powers. Effects resume after revival according to the game's rules, while death prevention continues to work.
- Fixed a dead teammate's Osty being predicted with zero maximum HP when multiple players have Osty.

Retains the fourteen-enemy-cycle horizon, the 3 HP loss target per cycle and doubled ordinary multiplayer search limits. Single-player keeps the upstream 0.43.2 path. This is a local patch package with no new GitHub Release. Offline comparisons with native game logic pass; live multiplayer remains unverified.
