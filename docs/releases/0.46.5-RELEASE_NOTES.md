# CombatSolver 0.46.5

## 简体中文

- 感谢 [fdkgf](https://github.com/fdkgf) 在 [issue #135](https://github.com/Torch1230/CombatSolver/issues/135) 提供的建议：单人搜索在已核对的放血等失血场景中，更早放弃已无法挽回战损的路线；仍有回血机会的路线继续保留。多人军师继续采用独立的选路方式。
- 修复与 Loadout 2 更新后的兼容问题：未配置怪物额外能力且接口兼容时，求解器可以正常搜索，不会仅因 Loadout 版本号变化而停用。配置怪物额外能力时仍会提示不兼容。

多人继续为手动军师试用：仅推荐本人的操作，最多推演十四个敌方回合，不预测队友后续主动出牌或用药；真实联机尚未完成验收。

## English

- Thanks to [fdkgf](https://github.com/fdkgf) for the suggestion in [issue #135](https://github.com/Torch1230/CombatSolver/issues/135): In reviewed single-player cases such as Bloodletting, the solver stops exploring HP-loss routes that can no longer recover the loss sooner. Routes with a remaining chance to heal stay in the search. The multiplayer advisor keeps its independent route selection.
- Fixed compatibility after Loadout 2 updates: combat search works when no extra monster powers are configured and the interface remains compatible, without rejecting a change to Loadout's version number alone. Configured monster powers still trigger an incompatibility notice.

Multiplayer remains an experimental manual advisor: it recommends only your actions, looks ahead up to fourteen enemy turns, and does not predict teammates' future active card or potion use. Live multiplayer validation is still pending.
