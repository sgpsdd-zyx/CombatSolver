# CombatSolver 0.40.3 - 多人手动军师 / Multiplayer Advisor

## 简体中文

这是 `sgpsdd-zyx/CombatSolver` 的 fork 版本，基于上游 `0.40.2`。

- 新增多人手动军师：点击「重新计算」，按当时全队状态推荐本人的出牌、目标和用药顺序。多人模式只提供建议，操作由玩家完成。
- 最多推演七个敌方回合，显示实际推演深度；计算预算不足或需要队友选择时，会标出提前停止的边界。
- 队友行动后保留旧建议并提示「战场已变化」，由玩家决定何时重新计算；新回合也不会自动重算。
- 药水与出牌一起规划，支持目标选择和本人选牌，保留逐瓶保护及强制用药设置。
- 单人继续提供原有的路线建议、执行本回合和连续全自动。

多人建议假设队友后续不主动出牌或用药，但照常结算被动效果、抽牌和受击。多人功能目前供试用，真实主机/客户端连接、三/四人组合和可见界面尚未完成验收。

### 安装

1. 使用《杀戮尖塔 2》`0.111.0`，单独安装并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` 或更高版本。
2. 下载本页附件 **CombatSolver-0.40.3.zip**，退出游戏，将内容解压到游戏的 `mods/CombatSolver/` 目录；`CombatSolver.dll` 与 `CombatSolver.json` 应直接位于该目录中，无需自行编译。
3. 确保只启用一份 Combat Solver；替换本地旧版，或先停用已订阅的上游副本。启用本 fork 后进入多人战斗，等待发牌和回合开始选择完成，再点击「重新计算」。

安装包包含 Mod、Windows 辅助程序及许可文件，不包含 RitsuLib。`CombatSolver.MemoryCleaner.exe` 仅供 Windows 使用，其他系统无需运行它。

## English

This is the `sgpsdd-zyx/CombatSolver` fork release, based on upstream `0.40.2`.

- Adds manual multiplayer advice. Click **Recalculate** to plan your own cards, targets and potion order from the party's current state. Players carry out the suggested actions themselves.
- Looks ahead up to seven enemy turns and shows the depth actually reached. The panel explains when the calculation stops early because of its budget or a required teammate choice.
- Keeps previous advice when teammates act and marks it as outdated. You decide when to recalculate; a new turn does not trigger an automatic calculation either.
- Plans potions alongside cards, including target selection and your own card choices, while respecting each potion's protected or required-use setting.
- Single-player retains route advice, **Play turn** and continuous **Auto** play.

Multiplayer advice assumes teammates take no further active card or potion actions, while their passive effects, draws and incoming damage still resolve. The multiplayer feature is available for trial use; live host/client sessions, three/four-player combinations and the visible interface have not yet been validated.

### Installation

1. Use Slay the Spire 2 `0.111.0` and separately install and enable [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` or later.
2. Download the **CombatSolver-0.40.3.zip** asset on this release, exit the game and extract its contents into the game's `mods/CombatSolver/` folder. `CombatSolver.dll` and `CombatSolver.json` must sit directly in that folder. No compilation is required.
3. Enable only one Combat Solver copy: replace an older local version or disable the subscribed upstream copy first. In multiplayer, wait for the opening draw and turn-start choices to finish, then click **Recalculate**.

The package contains the mod, its Windows helper and license files. RitsuLib is not bundled. `CombatSolver.MemoryCleaner.exe` is used only on Windows and does not need to be run on other systems.
