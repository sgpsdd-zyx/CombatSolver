# CombatSolver 0.41.3 - 多人建议修复 / Multiplayer Advice Fixes

## 简体中文

这是 `sgpsdd-zyx/CombatSolver` 的 fork 补丁版本，基于官方 `0.41.0`。

- 修复多人选路时，已获胜路线仍按较早的战斗状态比较，可能遗漏胜利建议的问题。
- 修复本机满血无损获胜后过早结束多人搜索的问题。现在会在原有搜索预算内继续寻找更合适的全队建议。
- 修复队友使用药水后，错误解除本机“至少用一瓶”要求的问题。
- 保留单人模式原有行为，以及多人手动计算、手动操作、最多七个敌方回合和每回合 3 HP 扣血目标。

多人功能仍供试用，未来推演假设队友不再主动出牌或用药；队友行动后请根据新局面重新计算。真实联机、三/四人组合、全角色与第三方 Mod 尚未完成全面验证。

### 安装与升级

1. 使用《杀戮尖塔 2》`0.111.0`，单独安装并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` 或更高版本。
2. 退出游戏，将 **CombatSolver-0.41.3.zip** 的内容解压到游戏的 `mods/CombatSolver/` 目录，替换旧版。DLL 与 JSON 应直接位于该目录。
3. 只启用一份 Combat Solver，重启游戏后使用。

安装包包含 Mod、Windows 辅助程序及许可文件，不包含 RitsuLib。非 Windows 系统无需运行 `CombatSolver.MemoryCleaner.exe`。

## English

This is a patch release of the `sgpsdd-zyx/CombatSolver` fork, based on upstream `0.41.0`.

- Fixed winning multiplayer routes being compared using an earlier battle state, which could cause a winning recommendation to be missed.
- Fixed multiplayer search stopping too early when the local player won at full health without taking damage. Search now continues within the existing budget to consider further advice for the team.
- Fixed a teammate's potion use incorrectly clearing the local player's requirement to use at least one potion.
- Preserved single-player behavior and multiplayer manual calculation and controls, the seven-enemy-turn limit, and the target of at most 3 HP lost per enemy turn.

Multiplayer remains a trial feature. Forecasts assume teammates take no further active card or potion actions; recalculate from the changed battlefield after they act. Live networking, three/four-player parties, every character and third-party mod have not undergone full validation.

### Install or Upgrade

1. Use Slay the Spire 2 `0.111.0` and separately install and enable [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` or later.
2. Exit the game and extract **CombatSolver-0.41.3.zip** into the game's `mods/CombatSolver/` folder, replacing the old version. The DLL and JSON must sit directly in that folder.
3. Enable only one Combat Solver copy, then restart the game.

The package includes the mod, its Windows helper and license files. RitsuLib is not bundled. Other systems do not need to run `CombatSolver.MemoryCleaner.exe`.
