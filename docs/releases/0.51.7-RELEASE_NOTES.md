# Combat Solver 0.51.7

## 简体中文

- 修复多人队伍中两名愚者向同一敌人射箭时，计算可能反复报“搜索动作回放失败”的问题。双方箭矢与拔箭所需的命中计数现按各自玩家独立处理。

## English

- Fixed repeated search-action replay failures when two Fools shoot the same enemy in multiplayer. Each player's arrows and the hit counter needed to retrieve them are now tracked independently.
