# CombatSolver 0.43.5 更新日志

## 简体中文

- 合入官方 0.43.1 与 0.43.2 的更新。保留本 fork 的多人手动军师、十四个敌方周期、长线选路和佩尔之眼修复。
- 修复英文等非中文语言下悬浮窗可能无法显示的问题，药水、成长和遗物面板的“收起”按钮正确切换语言。
- 单人成长策略增加“疯狂科学”：带有“改进”效果的能力牌可独立设置战后永久升级的战损额度；其他变体不计入此项成长。多人继续按战斗内表现选择路线。
- 单人同时设置“强制使用”和“智能使用”药水时，额外智能药根据只用强制药的路线判断是否值得消耗；必要时仍可用来保命。
- 改进战斗中生成卡牌与已支持第三方卡牌效果的兼容性；遇到未支持效果时明确提示。
- 路线缓存读写失败时仍可继续计算，符合条件的战斗录像采集失败也不会阻止路线显示和执行。
- 优化单人部分整场历史计数的计算。合并时补齐多人兼容，避免多人计算开始时或使用金斧等牌时因单人假设而中断。

多人仍只给建议，需要手动请求和操作；队友后续主动行动未纳入推演，不保证完成十四周期或找到全局最优路线。本地验证不代表真实联机验收。

感谢上游维护者、bingyang1132 对 PR #105 的贡献，以及 Natsuki 对 PR #117、#118、#119 的贡献。

## English

- Incorporated upstream 0.43.1 and 0.43.2 while retaining this fork's manual multiplayer advice, fourteen enemy cycles, longer-term route selection, and Pael's Eye correction.
- Fixed the overlay potentially failing to appear in English and other non-Chinese languages. The potion, growth, and relic panels now use the localized Collapse button.
- Added Mad Science to single-player Growth Strategy: its Power variant with Improvement has a separate HP-loss allowance for permanent deck upgrades. Other variants do not count toward this reward. Multiplayer continues to select routes by their combat outcomes.
- In single-player, when potions mix Always Use and Smart, additional Smart potions are judged against a route using only the required potions. They remain available when needed to save the fight.
- Improved compatibility for cards generated during combat and supported third-party card effects. Unsupported effects are reported explicitly.
- Route-cache read or write failures no longer prevent calculation. Failure to record an eligible combat no longer prevents the calculated route from appearing or being executed.
- Improved some whole-combat history calculations in single-player. Added multiplayer compatibility during integration to avoid interruptions at search startup or when using cards such as Gold Axe that read combat history.

Multiplayer remains manual advice. Teammates' future active actions are not modeled; completing fourteen cycles or finding a globally optimal route is not guaranteed. Local checks do not establish live multiplayer compatibility.

Thanks to the upstream maintainers, bingyang1132 for PR #105, and Natsuki for PRs #117, #118, and #119.
