# CombatSolver 0.47.2

## 简体中文

本版基于官方 0.47.1，更新内容以多人 fork 0.46.6 为对比基线。

- 合入官方单人搜索改进，更好地考虑能力牌、升级与成长的跨回合收益，以及抽牌、弃牌、零费牌和转火的配合。
- 改善单人用药时机与组合选择。混沌药水生成的药水不再重复计入用药机会成本，混沌药水本身仍计入成本；多人建议也采用这一计价方式。
- 新增单人“前两回合深入探索（实验）”设置，默认关闭。开启后可继续比较不同开局的完整战斗路线，最多计算 40 分钟，可随时停止；只采用战损与用药综合结果更好的完整胜利路线。多人模式不启用此项探索。
- 完善开局与回合准备选牌的搜索，正确记录相关路线的逐回合战损，并处理组合出牌、选牌及结束回合时的计算失败。
- 修复墨刃与不安油灯组合时的效果预测偏差。

多人继续为手动军师试用：仅推荐本人的操作，最多推演十四个敌方回合，不预测队友后续主动出牌或用药；烘焙手套选牌时仍可先计算，再由玩家确认。真实联机尚未完成验收。

## English

This release is based on upstream 0.47.1. Changes are relative to multiplayer fork 0.46.6.

- Incorporated upstream single-player search improvements for the cross-turn value of Powers, upgrades and scaling, and for combinations involving draw, discard, free cards and target switching.
- Improved single-player potion timing and combinations. Potions generated by Entropic Brew no longer incur an additional opportunity cost; Entropic Brew itself still counts. Multiplayer advice uses the same cost treatment.
- Added the single-player "Deep early-turn exploration (experimental)" setting, off by default. When enabled, it continues comparing complete combat routes from different openings for up to 40 minutes and can be stopped at any time. Only a complete victory with a better combined HP and potion outcome is adopted. This exploration is disabled in multiplayer.
- Improved searches involving openings and turn-start choices, recorded their per-turn HP loss correctly, and addressed calculation failures involving combined card plays, choices and turn-ending actions.
- Fixed effect prediction for Blade of Ink with Unsettling Lamp.

Multiplayer remains an experimental manual advisor: it recommends only your actions, looks ahead up to fourteen enemy turns, and does not predict teammates' future active card or potion use. You can still calculate advice while Toasty Mittens awaits your choice, then confirm it yourself. Live multiplayer validation is still pending.
