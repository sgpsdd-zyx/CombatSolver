# CombatSolver 0.51.6

## 简体中文

多人fork同步官方0.51.4与0.51.5，继续支持游戏0.113.0 Beta和RitsuLib0.6.11+。

- 修复大树将倾击杀后的群体伤害预测，以及射箭触发洪流巨人转阶段后插箭、虚弱和易伤的保留。旧角色获得射箭牌时也会正确计入首个箭槽。
- 修复横祸在空抽牌堆下、狠揍自动打出群攻君王之剑时的随机序列偏差；修复安可与探寻打击等选牌效果组合时的计算失败。
- 修复狂喜批量变牌后的手牌顺序，以及准备时间、潜伏根系、覆甲、再生和灾厄的结算顺序，改善跨回合预测与路线续用。
- 单人智能药水尝试双药方案失败时保留已有路线；提前击杀全部敌人后不再错误计算后续能力牌。
- 修复单人回合开始选牌后的等待超时与窥视战场后计划选牌被忽略的问题，改善单步和自动执行的跨回合接续。
- 同步部分平台计算和内存释放失败的修正；系统内存清理按钮仅在Windows显示。

多人继续手动请求建议、自己操作，不预测队友主动行动，最多推演十四个敌方周期。多人仍为试用功能，尚未完成真实联机验收。

## English

This multiplayer fork incorporates upstream 0.51.4 and 0.51.5, with continued support for game 0.113.0 Beta and RitsuLib 0.6.11+.

- Fixed Timber's splash damage after a kill and preserved Impaled, Weak, and Vulnerable when an arrow triggers Waterfall Giant's phase transition. Other characters now receive their first arrow slot when obtaining Shoot cards.
- Fixed RNG drift from Catastrophe with an empty draw pile and from Beat Down automatically playing an all-enemy Sovereign Blade. Fixed calculation failures when Encore interacts with selection effects such as Seeker Strike.
- Fixed hand order after Ecstasy transforms multiple cards and the resolution order of Prep Time, Hidden Roots, Plating, Regen, and Doom, improving predictions and route continuation across turns.
- Single-player Smart potion searches retain the existing route when an optional two-potion search fails. Power follow-up probes stop when a route has already defeated every enemy.
- Fixed single-player waits after turn-start selection and planned hand selections being ignored after peeking at the battlefield, improving continuation for single-step and automatic execution.
- Incorporated fixes for calculation and memory-release failures on some platforms. The system memory cleanup button is shown only on Windows.

Multiplayer retains manual requests and player-controlled actions, does not predict teammates' active actions, and searches up to fourteen enemy cycles. It remains experimental and has not been validated in live network play.
