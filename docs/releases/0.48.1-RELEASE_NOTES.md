# CombatSolver 0.48.1

## 简体中文

相对于多人 fork 0.47.3，同步官方 0.48.0。多人继续提供手动军师，保留烘焙手套选牌期间计算、本人贡献目标和最多十四个敌方回合；以下单人搜索优化仅用于单人模式。

- 感谢 [ltlly](https://github.com/ltlly) 的 [PR #188](https://github.com/Torch1230/CombatSolver/pull/188)、[PR #199](https://github.com/Torch1230/CombatSolver/pull/199) 和 [PR #200](https://github.com/Torch1230/CombatSolver/pull/200)：单人复杂战斗减少重复模拟和对低价值路线的反复计算，并利用已找到的胜利路线缩小后续尝试范围。具体收益取决于牌组、场面和搜索设置。
- 单人五个角色、所有原版怪物均采用已知回血来源判断，减少反复尝试缺少可靠回血的高战损路线。已有再生、实际持有的回血药水、战后回血、明确的卡牌与遗物回血，以及成长和保命目标仍被考虑。修书小刀仅在持有时计入；炼制药水尚未产生的随机回血不提前计入，实际药水效果保持原样。
- 感谢 [ACGNnsj](https://github.com/ACGNnsj) 的 [PR #190](https://github.com/Torch1230/CombatSolver/pull/190)：单人前两回合深入探索减少重复尝试，达到设置中的可接受战损目标时及时停止追加探索，继续遵守成长、遗物和用药目标。该实验功能仍默认关闭。
- 感谢 [ACGNnsj](https://github.com/ACGNnsj) 的 [PR #190](https://github.com/Torch1230/CombatSolver/pull/190)：在“问题反馈”设置中新增“保留本进程全部战斗日志”。默认关闭，开启后从下一场战斗开始保留同次游戏的详细战斗日志，方便分析多场战斗；会增加磁盘占用，已清理的日志无法恢复。
- 感谢 [ltlly](https://github.com/ltlly) 的 [PR #147](https://github.com/Torch1230/CombatSolver/pull/147)：减少重复卡牌选牌时的多余计算，并正确区分当前费用相同、费用持续时间不同的卡牌，例如“本回合免费”与“整场战斗免费”。
- 感谢 [fengzhenhong](https://github.com/fengzhenhong) 的 [PR #197](https://github.com/Torch1230/CombatSolver/pull/197)：修正充能球数值预测，以及回合结束时临时力量、敏捷和集中效果的处理顺序，减少预测与实战结果的偏差。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 的 [PR #194](https://github.com/Torch1230/CombatSolver/pull/194)：修复部分带余像的单人路线在调整出牌顺序后，因攻击目标变化而中断计算的问题；调整后的路线无法执行时保留原可用路线。
- 感谢 [yM7-1](https://github.com/yM7-1) 的 [PR #198](https://github.com/Torch1230/CombatSolver/pull/198) 和 [PR #201](https://github.com/Torch1230/CombatSolver/pull/201)：修复地精死亡召唤新敌人时，目标名称处理异常导致计算中断的问题；修复单人智能药水在部分开局路线中中断计算的问题，并减少单人预测与部分第三方模组的调用冲突。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 的 [PR #194](https://github.com/Torch1230/CombatSolver/pull/194)：跑局统计文件损坏或统计处理异常时，停止本次统计，战斗路线执行仍可继续；不完整记录会明确标记，避免当作完整跑局上传。
- 改善“强制释放内存”的回收效果，帮助降低计算结束后的游戏内存占用；实际效果受平台与运行环境影响。

多人不会预测队友后续主动出牌或用药；队友改变战场后仍需自行决定何时重新计算。真实联机效果仍待验证。

## English

Changes since multiplayer fork 0.47.3, incorporating upstream 0.48.0. Multiplayer retains manual advice, calculation during Toasty Mittens choices, local contribution goals, and a horizon of up to fourteen enemy cycles. The single-player search improvements below apply only to single-player.

- [PR #188](https://github.com/Torch1230/CombatSolver/pull/188), [PR #199](https://github.com/Torch1230/CombatSolver/pull/199), and [PR #200](https://github.com/Torch1230/CombatSolver/pull/200) by [ltlly](https://github.com/ltlly): Complex single-player fights require less repeated simulation and exploration of low-value routes. Wins already found also narrow later attempts. Gains depend on the deck, combat state, and search settings.
- All five single-player characters and all vanilla enemies use known healing sources to reduce repeated attempts at high-HP-loss routes with little reliable healing. Existing Regen, held healing potions, post-combat healing, known card and relic healing, growth goals, and survival resources remain accounted for. Book Repair Knife is considered only when held. Potential random healing from Alchemize is ignored until generated; actual potion effects are unchanged.
- [PR #190](https://github.com/Torch1230/CombatSolver/pull/190) by [ACGNnsj](https://github.com/ACGNnsj): Single-player early-turn exploration makes fewer repeated attempts and stops additional exploration when the configured acceptable HP-loss target is met, while respecting growth, relic, and potion goals. This experimental feature remains off by default.
- [PR #190](https://github.com/Torch1230/CombatSolver/pull/190) by [ACGNnsj](https://github.com/ACGNnsj): Added “Keep all combat logs this game session” to Bug Reports settings. It is off by default and takes effect from the next fight, retaining detailed logs across fights in the same session. This uses more disk space; deleted logs cannot be recovered.
- [PR #147](https://github.com/Torch1230/CombatSolver/pull/147) by [ltlly](https://github.com/ltlly): Reduced redundant work when choosing duplicate cards. Cards with identical current costs but different cost durations, such as free this turn and free this combat, are now treated as distinct choices.
- [PR #197](https://github.com/Torch1230/CombatSolver/pull/197) by [fengzhenhong](https://github.com/fengzhenhong): Corrected Orb value predictions and the processing order of temporary Strength, Dexterity, and Focus effects at turn end, reducing differences between predicted and actual combat results.
- [PR #194](https://github.com/Torch1230/CombatSolver/pull/194) by [s1f102500012](https://github.com/s1f102500012): Fixed failures when reordering single-player plays involving Afterimage changed the available attack targets. The original usable route is retained when the adjusted route cannot be executed.
- [PR #198](https://github.com/Torch1230/CombatSolver/pull/198) and [PR #201](https://github.com/Torch1230/CombatSolver/pull/201) by [yM7-1](https://github.com/yM7-1): Fixed target-name failures when Gremlins summon new enemies on death, fixed Smart potion calculation failures in some single-player opening routes, and reduced some call conflicts with third-party mods during single-player prediction.
- [PR #194](https://github.com/Torch1230/CombatSolver/pull/194) by [s1f102500012](https://github.com/s1f102500012): Corrupt run-statistics files or statistics-processing failures stop statistics collection for that run while allowing combat route execution to continue. Incomplete records are marked to prevent uploading them as complete runs.
- Improved the effectiveness of Free memory to help reduce game memory usage after calculations finish. Results depend on the platform and runtime environment.

Multiplayer does not predict teammates' future active card or potion plays. Decide when to recalculate after teammates change the battlefield. Live multiplayer remains unverified.
