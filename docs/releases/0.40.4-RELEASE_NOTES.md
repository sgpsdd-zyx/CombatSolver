# CombatSolver 0.40.4 - 多人计算启动修复 / Multiplayer Calculate Fix

## 简体中文

这是 `sgpsdd-zyx/CombatSolver` 的 fork 修复版本。

- 修复多人战斗点击「开始计算」或「重新计算」后面板完全没有反应的问题，房主和加入房间的玩家均适用。
- 等待动作或选牌结算时显示提示；启动失败时显示错误，处理后可以重新计算。
- 战斗记录以本机玩家为准，正确区分本人和队友的伤害、治疗。

多人继续只建议本人的出牌和用药，最多推演七个敌方回合；操作和重算时机由玩家决定。真实联机和可见界面尚未完成验收。

### 安装与升级

1. 使用《杀戮尖塔 2》`0.111.0`，单独安装并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` 或更高版本。
2. 退出游戏，下载本页附件 **CombatSolver-0.40.4.zip**，将内容解压到游戏的 `mods/CombatSolver/` 目录并替换旧版；DLL 与 JSON 应直接位于该目录，无需编译。
3. 只启用一份 Combat Solver，重启游戏后进入多人战斗，等待发牌与回合开始选择完成，再点击「开始计算」。

安装包包含 Mod、Windows 辅助程序及许可文件，不包含 RitsuLib。非 Windows 系统无需运行 `CombatSolver.MemoryCleaner.exe`。

## English

This is a fix release for the `sgpsdd-zyx/CombatSolver` fork.

- Fixes **Calculate** and **Recalculate** appearing to do nothing in multiplayer combat, for both hosts and joining players.
- Shows a message while waiting for actions or card choices to finish. Startup errors are displayed so you can resolve the issue and retry.
- Records the local player's damage and healing separately from teammates.

Multiplayer continues to advise only your own cards and potions, looking ahead up to seven enemy turns. You carry out actions and decide when to recalculate. Live multiplayer and the visible interface have not yet been validated.

### Install or Upgrade

1. Use Slay the Spire 2 `0.111.0` and separately install and enable [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) `0.6.0` or later.
2. Exit the game, download **CombatSolver-0.40.4.zip** from this release and extract it into the game's `mods/CombatSolver/` folder, replacing the old version. The DLL and JSON must sit directly in that folder. No compilation is needed.
3. Enable only one Combat Solver copy. Restart the game, enter multiplayer combat, finish the opening draw and turn-start choices, then click **Calculate**.

The package includes the mod, its Windows helper and license files. RitsuLib is not bundled. Other systems do not need to run `CombatSolver.MemoryCleaner.exe`.
