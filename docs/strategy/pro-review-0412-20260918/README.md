## 本轮取舍

主方案改为“证据一致的保守多人 Beam”：先修终局事实、多人错误早停与本机根前用药输入，再处理同一已知发布时点的完成池压缩。低成本回退为只保留这三项正确性修复和现役三通道 Beam；研究结束时尚未实施，后续实施采用该回退范围，具体结果见[实施记录](implementation.md)。

正式撤回上一轮“两步挑战优先”。同预算玩具实验同时给出获益与退化例，尚无生产延迟组合失败输入证明它应占用默认预算。资源归属观察与改变本机/队友风险次序分开；集火/救援与长组合先定位第一次丢路，暂不新增权重、队友情景、搜索器或预算。

## 验证范围

本轮已运行一次新的排序入口探针：编译 0 错误、1 条合成节点空值警告，执行退出码 0。它直接调用已有生产 DLL 的排序函数，复现胜利被旧检查点遮蔽并被截断，以及资源/尾部事实比较；没有重新构建生产 DLL，没有运行搜索模拟器或游戏。

Pro 的 18 项抽象运行包括独立 840 排列、216 组三元比较及 55,296 组固定深度三元关系；本地阅读脚本与输出，没有重复执行。本地生产函数探针、外部抽象实验和仓库历史合同是三份不同证据，不能互换。真实搜索入口可达性、原生差分、双端联机、胜率与可见性能仍未验证。
