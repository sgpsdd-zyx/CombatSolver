## 2. 用户真正需要什么

我在《杀戮尖塔 2》的多人合作模式中使用本 Mod，**只有我安装 Mod，其他玩家正常手动玩，不安装、不发送计划、不保证配合**。我可能是房主，也可能是客户端。希望它帮助我更聪明地决定本人出牌顺序、攻击目标、格挡、控制、铺垫、选牌、救援和用药。

多人模式只在我手动请求时捕获当前全队状态，再计算本人的建议；我自己执行。不得增加自动出牌、自动重算、自动结束回合或接管真人队友。队友已经做过的动作属于当前事实，其未来动作属于不确定性。

已确认的风险偏好为：每个敌方周期最多 3 HP 本机扣血的目标，在此范围内尽量获得有价值的输出，优先避免致命风险；不要求每周期主动掉血。包含本周期已支付扣血和自损，治疗、重新计算、额外玩家回合不重置额度，未用额度不结转。允许研究更合理的目标，但改变该含义或默认风险水平必须单列为需要用户决定的产品变化。

当前最多覆盖七个敌方周期，预算不足可以提前返回。可以设计近端精确、远端近似或自适应的方案，但要保留对未来 5-7 周期铺垫价值的判断；近似预测不能冒充完整受击验证。

首个可实施版本应在普通桌面电脑本地运行，优先无需训练、无需运行时云端 LLM。**只允许修改多人策略，原版单人策略保持原路径、原参数、原行为。保持简洁和可维护性，禁止为研究方案先造一整套框架。**
