## 现役定义

- 阶段初始有效敌人生命 H，存活参与者 n，目标 D=ceil(H/n)，默认3敌方周期截止。期限按真实 RoundNumber，不是本机 TurnNumber。多人上限仍14，普通时间/节点x2，固定原值；无预算/Beam额外扩张。
- Runtime 保存阶段初始HP、参与者身份、原生伤害计数和绝对截止。每次手动请求只更新已观察事实；同回合、治疗、额外玩家回合不刷新。到期重建；死亡/复活改变人数时保留本阶段截止，明确记录旧目标/旧进展后重建。战斗结束清空，不跨重启持久化。
- 进展 P=min(本机实际伤害，H-当前有效敌人HP-其他/未知归属伤害)。它可以为负；治疗、复活、新生命会冲回进展。原生 UnblockedDamage 已经排除过杀，不再相减。dealer=本机或PetOwner=本机才支付份额，未知来源不归功自己。跨重算从同一阶段起点计算，不能相加各次已封顶净进展。
- 不改变真实敌人HP或 AllEnemiesDead；只打够份额不能早停或跳过反击。真实清场在阶段期限以内替代个人目标，期限之后的清场不能倒填为阶段达标。

比较顺序为用药要求、预测风险、首个敌方周期风险、阶段本人死亡、可比较性、阶段真胜利，再比较连续成本。比较周期在资格过滤后、4B压缩前冻结，为已观察最大周期与阶段剩余周期的较小值。缺周期的非终局节点仍是未知；无完整首周期显示受击未评估。

令 R 为本次根HP，M为根最大HP。阶段成本为 max(0,R-HP)+max(0,M-MaxHP)+药水战略代价+R×救命次数+R×阶段减少的存活人数+max(1,R)×clamp((D-P)/max(1,D),0,2)^2。另加0.25×R×剩余敌HP/根敌HP，并减去0.5倍条件尾值。阶段胜利不再计缺口。小怪减员通过实际后续敌人行动与血线体现，存活敌人数为后续同分项；没有声称精确估值所有团队辅助。

尾值只读取已经生成的更深检查点：增量进展最多按一个D折算R，减后续HP/最大HP、药水、救命与队友死亡代价，再按0.95^(距离-1)折价；本人后续死亡另扣R。后续风险是条件代价而不是硬性要求本机独力清场。最初使用按尾部长度平均再乘0.2的候选把晚回本压掉，已放弃；保留反例与最终对照，参数不是统计校准结论。

## 所有权与限制

`MultiplayerContributionCapture/Session` 属Runtime；不可变Objective和PlanValue/QuotaSelection属Search。已有 RecordDamageReceived 捕获本机/总实际伤害，分支按值Fork。周期链只含原始数值；去重/转置标签和严格增量校验消费它，不进入战斗状态键/ContinuationStamp。最终前沿最多4B，保护低成本、高进展和达标代表；预测风险候选不能支配可靠候选，未达标不是不可达。不可变见证不持有模拟器，父链模拟器按现有Phases释放。

返回动作通常截至比较边界；显式强制用药若在后续完成，截断不得删去满足要求的动作。原有药水资格、合法性与手动操作不变。最大已观察周期独立记录，不能把它当返回路线深度。旧3 HP、C/A覆盖升级均退出；旧窗口合同命令显式指向v0.43.6，新合同覆盖当前政策。

编译范围排除 `docs/**/*.cs`：6 Pro归档探针是固定旧API研究材料，不能因删除旧额度字段而进入生产编译并触发CS1061。未改写原始交付以掩盖不兼容。CoverageCatalog另因RitsuLib多程序集引用与上游两类新增证据状态而无法运行，已同步；带限制的聚合证据仍不授予Runtime覆盖，完整失败/成功日志保留。
