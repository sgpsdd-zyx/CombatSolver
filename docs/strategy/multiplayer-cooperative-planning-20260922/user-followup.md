# 用户补充：取消 3 HP 优先，研究贡献配额

2026-09-22，首轮提交后补充。研究范围保持设计与验证，不实施或发布。

用户明确允许彻底取消每周期 3 HP 策略，并提出候选：以敌人总剩余 HP / 多人人数作为伤害目标，或探索二分查找目标；先达到足够输出，再在达标路线中优化战损，以复用单人求解器能力。这是启发，不要求固定采用该方案。

曾通过同一 6 Pro 研究会话发送补充，界面短暂出现新的用户消息及 `Pro thinking`。随后页面恢复原研究流，未显示这条补充，因此不把第一次尝试当作已接收。首轮结束后另行提交[配额专项请求](quota-review-request.md)，界面确认独立用户消息、研究过程与最终 `Worked for 18m 50s` 回复；最终报告明确改为配额/前沿首版并删除软 3 HP。要求纳入：

- 贡献配额、epsilon-constraint 与伤害/战损 Pareto 前沿，作为主方案的正式对照。
- 虚拟目标完成判据与修改真实敌人 HP 的区别；缩血会提前死亡并改变行动、触发与威胁，不是等价复用。
- 整场分工、每次重算的剩余分工、角色差异、死亡队友、已付贡献、截止时间及危险目标。
- 二分只在嵌套且可靠的可行性判断下成立；限时 Beam 未找到见证属于 Unknown。比较一遍枚举前沿与多次重启的全部工作成本。
- 达到配额后仍需评估存活敌人的真实反击，不能当作战斗胜利。
- 易伤等团队增益、救援、资源代价与贡献归因；不能重复计价或强迫辅助角色平均承担直接伤害。

同时传递本地 10 项生产比较函数的合成输入观察：超过 3 HP 的 1 点损失优先于活着获胜、保住队友或多打 90 伤害；共同周期事实可比时，不同探索估值不参与最终质量排序。这些是函数级证据，不是可达牌序、出现频率、原生差分或游戏质量结论。

专项没有新增或重跑实验。它复用首轮结果作为“应先验证便宜方案”的依据，没有把 R 的 F_cheap 成绩改记为新配额或无软 3 HP 模式的成绩。结论区分：配额/前沿是首选架构，`本机直接伤害 >= 总 HP / 人数` 是强基线而非完整协作硬门槛；同时保留未达标方案，暴露临界一两点输出带来的巨大代价跳变。最终严格达标选择并未自动解决该跳变，本地取舍详见[审查](pro/local-review.md)。

## 后续范围修订：不预测队友

用户原话：“队友行为预测大可不必，当前就当队友行为是混沌的就行，如果预测了，但队友没按你想的打（可能队友水平也不够），那不是白预测了”。

据此从当前计划移除主动队友策略、随机行为模型、虚拟 DPS 和合作反事实。只枚举本机行动，将队友未来操作保持为未知；已发生的状态、既有被动效果与本机能兑现的增益照常计算。队友行动后手动重算，不自动请求。不预测队友不能演变为要求本机独自清场；当前目标仍是本机贡献与战损权衡。纯团队辅助的未知收益是明确限制，不以固定奖金填补。此为用户后续设计约束，未再次发送 Pro，也没有新增行为验证。
