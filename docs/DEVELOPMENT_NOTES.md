# CombatSolver 开发笔记

当前公开版为 [0.50.2](releases/0.50.2-PUBLISH.md)。本轮合入官方 `06083d36 / 0.51.3`，正在完成多人 fork 0.51.4 发布验收。历史见[开发归档](archive/development/README.md)。

## 0.51.4（开发中）

- 迁移游戏 0.113.0 与 RitsuLib 0.6.11 API，合入官方愚者、领域、恐惧/极速模式、实例状态与结算修复。官方首领追加搜索仅用于单人，多人手动入口、贡献政策与预算保持独立。
- 多人逐玩家状态键与续用戳补入箭槽、旋律、ShowOff 来源、NonCombatGeneration 与非奥斯蒂宠物；额外回合冻结逐参与者选定来源，仅消费该来源。全队旋律跟随原生历史窗口清理，覆盖未参加额外回合的队友。模式相关怪物参数保留多人目标顺序。
- 更新后采用游戏 0.113.0 / RitsuLib 0.6.12。定向复现并修复队友宠物状态未进入比较、额外回合残留队友旋律两项合并缺口；单人双根对照177字段及完整路线一致。合并冲突、实际测试与初始依赖失败见[本轮记录](archive/strategy/upstream-0513-merge-20261113.md)。
