- 金币新增的 null-child 跑局监听在多人按分支 Hook 资格构造整段序列，兼容死亡和复活；单人保留官方来源与拒绝边界。金纸延迟虚无计数统一归各持有者遗物，不保留多人重复状态。

## 首次失败与修正

1. 新增金币合同最初在托管单人传输下加入第二名玩家，使原生准备人数提前满足并自动推进。测试侧为本合同固定真实双人准备数量；这只是宿主前置条件修正，未改生产网络逻辑。
2. 修正准备数量后，真实复现官方新金币监听遇到死亡队友时的显式拒绝。多人改用既有分支 Hook 活动状态，派发前固定序列；覆盖死亡后本机获金及从死亡根复活后的队友获金，单人方法体保留官方行为。
3. 原生虚空形态用例首次到第二回合停在新档首次洗牌教程。测试 fixture 在播放前标记该教程已完成后通过完整状态对账，没有增加超时或改游戏回合行为。
4. 迁移的旧 transposition 工具仍引用已删除的每周期 HP 额度。生产结构已使用贡献伤害，工具改为核对本机、全队、无来源三类伤害标签，并保留原始独立前沿算法对照。
5. CoverageCatalog 合并了双方同名状态枚举，首次工具构建暴露重复成员；保留官方两个已记录边界状态，仅追加 fork 的 ExplicitScope。随后新证据条目缺少必需 Evidence 字段导致明确失败，补齐来源字符串后 3,035 项生成与指定检查通过，未通过默认值跳过。
6. GC diagnostic-failure 的 `Exercise an actual region and collection` 前提失败。保留原日志，不扩大内存预算或重复试跑；原生常规 GC 限额及另外两个作用域合同已独立通过。
