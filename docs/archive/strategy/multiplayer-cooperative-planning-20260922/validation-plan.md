# 后续落地的可证伪验证计划

本文保留研究时提出的完整验证候选，已移除队友行为预测。生产首版实际执行的合同、对照与未覆盖项见[实施记录](implementation.md)；本表不是全部通过清单，A/Q/F/F0 四算法与独立真人闭环仍未完成。

## 比较对象与共同条件

应保留现役 0.43.6 作为 A，比较以下本机规划候选：

1. **Q：贡献配额。** 固定真实战斗状态与截止时间，在达标路线中优化战损；不按 3 HP 优先，不修改敌人 HP。
2. **F：一遍枚举的权衡前沿。** 与 Q 使用同样目标和模拟模型，区别只是共享候选、见证与预算，避免逐阈值重启。
3. **F0：便宜进展/代价回退。** 不含 3 HP，使用本机短续行及有界末端估值，不规划队友主动行动，用于检验配额及前沿的额外成本是否有收益。

这里 F 是本地前沿代号，不是首轮外部 `F_cheap`；F0 也只是未运行的新设计。区分本机 `H/n` 配额、严格/弹性选择与搜索工作复用，不能合并归因。`H/n` 不代表队友会贡献其余伤害，模拟中不提前扣除这部分血量。

主动队友情景 S、合作反事实、ready/actor/choice 扩展以及更换 MCTS 均不在当前落地清单。外部研究中的这些候选保留作历史材料。

所有准备、本机候选生成、Fork、选牌、回合推进、末端评价、重放、排序和结果发布都计入同一请求。报告实际墙钟、展开/转移/选牌次数、峰值存活分支与停止原因；抽象工作单位、生产节点和毫秒分别列出。

最终外评固定已选本机当前动作，再由评估方给出队友实际操作及后续状态。规划器不读取评估脚本、不拟合队友风格；相同新根上的行为应与不可见的评估脚本无关。队友插入动作改变合法性时，不能强行执行旧完整动作束；按明确的手动重算协议继续。外部不同操作只是检验适应性，不是给规划器增加预测情景。

另外单列连续手动重算的闭环协议，检验固定阶段期限、可倒退净进展和任务重建；旧外部只选一次动作的协议不能代替这一项。旧 R 的八个根现在也参与了设计依据，只作固定回归；最终新方案必须使用新的留出根。

## 分层执行

| 层 | 最小输入与目的 | 通过标准 | 不能外推 |
|---|---|---|---|
| 语义前置 | 两玩家，本机任意索引；本机增益/选牌、已存在的队友被动效果、死亡/额外回合与父子 Fork | 相同本机动作下 actual/simulated 全状态严格一致，根不变，资源及效果持有者正确；不生成队友主动动作 | 不证明搜索能发现好动作 |
| 当前决策 | 固定短预算的目标根 + 一个防御哨兵 | 新候选进入、保留、获得相同评价并实际被选；没有隐藏超预算 | 不证明整场更优 |
| 时限/配额 | 配额达成仍存活敌人、不同达标周期、重算与已付贡献 | 不触发假胜利，统计无重复；Unknown 不转不可行；终端按真实敌方阶段 | 不证明选定配额最优 |
| 同预算质量 | 配对 A/Q/F/F0，固定根和相同外部推进协议，留出怪物成长/牌序/角色组合 | 分开报告胜负、团队生存、HP/资源、击杀时间和伤害曲线；逐负例解释 | 不可用内部评分代替质量 |
| 信息边界 | 不同隐藏牌序却同一观察；同一根配不同的外部队友操作脚本 | 规划器不偷看隐藏状态或未来队友脚本，不生成队友行动或虚构其伤害；实际新根捕获后才能改变计划 | 不证明未知队友下永远最优 |
| 单人隔离 | 现役官方同根哨兵与入口计数 | 完整路线及非时序字段不变，多人入口零进入 | 不代表全角色回归 |
| 真人评价 | 后续收集获得授权的多人根与独立玩家盲评 | 评估者不知算法，记录可执行性/配合要求/胜负；覆盖多种队友与难度 | 少量精选根不能声称超过平均人类 |

默认遵守仓库 L1/L2/L3 路由：策略用短搜 + 哨兵，阶段账本等新增跨回合状态单列生命周期合同，最终候选才做所需增量或整场。无需为了不预测队友而扩展其主动出牌语义。普通无人请求不超过 120 秒；超时缩小夹具，不放大内环等待。只有用户授权可见性能验证时才运行可见 Steam。

## 必留反例

| 反例 | 希望区分的问题 |
|---|---|
| 易伤供本机后续攻击；同一根外部队友利用/未利用易伤 | 本机兑现收益照算，未来队友伤害不能作为已实现进展或固定加分 |
| 同样总伤害，危险小怪死亡与首领少量掉血 | 总伤害不是唯一团队收益 |
| 成长快的敌人；普通稳定来伤敌人 | 进攻压力需要随时间变化，不能恒定卖血偏好 |
| 近端确定致死与远期条件性致死 | 避死事实与模型风险分层，不把全部未知未来当实际死亡 |
| 打够配额但没有防御，仍活着的敌人致死 | 虚拟达标不能改写真胜利 |
| 辅助/救援角色；队友已经濒死 | 即时治疗、格挡与已建模生存收益照算，不用其假想未来输出给救援定价；辅助价值的盲点单列 |
| 长线投资来得及回本；目标被队友提前击杀；战斗提前结束 | 收益兑现与投资机会成本 |
| 已有易伤/控制，继续重复叠加；过杀；Boss 无效控制 | 不按图标、层数或名义伤害刷分 |
| 治疗自损循环；复活；敌人回血、转阶段、召唤 | 贡献/代价账本不刷分，敌人集合口径稳定 |
| 相同可见状态、不同未知未来牌序 | 防止策略融合和后见之明 |
| 玩家阶段交错：先增益后队友攻击；队友先攻击 | 当前动作束不应被误当成现实原子事务 |
| 队友实际操作改变血线、状态和合法目标 | 手动重算使用新事实，不暗中预测其下一步或沿用旧预测分数 |
| 窄 Beam 下先铺垫后兑现的组合 | 探索保护不能只靠最终评分 |
| 极低预算、很多根候选、昂贵选牌 | 前沿管理和额外评价会抢走本机枚举；退化必须记入结果 |
| 二分的某个阈值搜索超时、另一更高阈值有见证 | 不把 Unknown 当 Infeasible；已有见证允许复用 |
| 重算前后已付伤害、队友死亡、怪物转阶段 | 配额及人数分母的口径不能漂移 |
| 输出 19/战损 0 与输出 20/战损 10，目标 20 | 有界前沿本身不能消除硬门槛代价跳变，须比较目标和选择政策 |
| 纯支援只有未来队友能消费；已有队友被动效果持续结算 | 未知主动收益不伪造；被动事实不能误删，不以完美辅助排序作为本版承诺 |
| 初次达标后敌人治疗；个体未达标但全队已清场 | 不锁死净进展，不把个人配额置于真实任务结束之前 |
| 多人血量很高，本机达标而敌人未死 | 不要求本机独力清场，不用“队友永久不出牌”把远期所有风险提升为当前必然失败 |

## 停止或否决条件

任一语义错误先停止该根的策略比较。规划器若生成队友主动动作、按预估 DPS 扣血或读取未来评估脚本，违反当前范围。若本机参考推演又被当成必须单独清场的硬要求，导致持续纯防守，应否决对应目标/风险规则。若 Q/F 只在随意降低伤害目标后显得更省血，不能称改善；若任一候选以更高本机/团队死亡代价换取表面高输出，需明确交易而非汇总为正收益。

“超过人类平均水平”是后续验证命题：需预先定义玩家样本、难度、角色/Mod 栈、信息条件、计算时间和度量，做独立盲评或实际游戏比较。本文没有给出该结论。
