初始环境：macOS arm64 游戏程序集缺少 Fool/DreadRunModel，安装 RitsuLib 0.6.10，仅含到 0.111.0 的 compat 目录。官方要求游戏 0.113.0、RitsuLib 至少 0.6.11。离线宿主也直接引用这两项，因此新版依赖是编译、离线测试和原生无头测试的共同前提。

初次 Release 构建在引用验证阶段失败（2.48 秒，缺 `compat/0.113.0/STS2-RitsuLib.dll`）。用户更新后游戏为 0.113.0、RitsuLib 为 0.6.12；修正显示函数参数、撤回准备与选牌栈 API 后，主项目和离线宿主 Release 构建均零警告、零错误。一次错误启动加载了尚未重建成功的旧宿主，MissingMethodException 不算本轮行为证据；随后使用成功构建的宿主。
