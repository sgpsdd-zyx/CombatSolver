基线为六 PR 合并及已知回血策略提交 `bb0e0129`。用户要求把 ltlly 的巨型千足虫剪枝思路推广到五角色、全部原版怪物：忽略未来随机炼药回血；修书刀只在实际持有时计算，未持有时不预留。其他实际持有的回血资源、时候未到及成长策略保持。

## PR #200 为什么更快

ltlly 的 [PR #200](https://github.com/Torch1230/CombatSolver/pull/200) 主要收紧剩余回血估计：

1. 生成牌入口和未知生成结果原来使剩余回血返回 `int.MaxValue`，于是未完成路线可假设将来补满缺血，很难证明它已经输给完整胜利路线。储君/铁甲的受限原版根复用八池 545 张牌、178 种 Power 的生成闭包；原版随机生成排除时候未到、狂宴、炼制药水等来源，生成与变牌不会因此凭空引入玩家治疗。千足虫重新接合只治疗敌段，奥斯提治疗只治疗宠物。
2. 储君成员明确不能用药，或分支已达到显式用药上限时，未用再生药水不再贡献将来治疗剂量。已生效再生继续计入，自动消费不占显式额度。再生总剂量 n 的保守剩余量为 n(n+1)/2，再加战后治疗。
3. 完整胜利已经找到后，若某条路线即使使用剩余治疗仍损血更多，原有 incumbent 剪枝可以停止展开。后续组合成员也使用已有纯值胜利界。少展开路线进一步减少动作模拟、分支复制、选牌、分配和 GC。

这是减少搜索工作量。PR 没有增大预算、重写千足虫 AI，或给每次模拟单独带来固定倍数的加速。

## 本次推广

已知来源策略本身在上一提交就接入了五角色、任意原版敌人，且对未持有的修书刀不预留回血。它不需要按角色复制五份牌表或按怪物复制准入名单；随机炼药仍按原版执行，只是不计尚未发生的随机回血。

本次补上外围限制：

- 零 HP 额度的遗物计数目标原来只在机器人/感染棱柱/初始零治疗证明下允许生命界剪枝，现在使用冻结的通用策略或封闭证书，对五角色及所有原版遭遇生效。分支自己的剩余回血仍逐次计算；完整余量的真实回血来源自然保持保守。
- 后续宽度/能力成员可以复用上述零额度目标的完整无药胜利界。成长目标和正 HP 额度目标仍走原保路，不用普通生命界替代收益预算。
- 遗物目标下同血量的较晚回合继续保留，以便改善计数；只剪已经严格多损血的路线。
- 提前开局完整路线的既有入口也接受通用已知来源资格，能在旧狭窄闭包以外建立后续成员可用的胜利界。沿用原节点/时间账本及政策门。

再生、实际持有的回血药水、固定战后治疗、时候未到、狂宴、恶魔之舌、修书刀、五轮之书及保命资源继续保护。当前未知 Mod 语义或未决选择使用明确的保守边界。通用策略按用户要求忽略未来随机回血，与原版封闭语义证书的证明口径分开。
