## 变更与复用范围

- 合并提交 `3f4356b0` 解决六处冲突。抽牌保留已验证的正常/后置回调与分支计数；最大能量采用上游冻结的基础值和分支回合规则；社区材料采用上游已发布归档链接。
- 在已有组件证书根内复用此前原生证明的同回合及更晚回合药水成本修复：等HP界只有在分支已花成本不低于完整见证时才关闭，缺失见证成本保持分支。
- 组件证书根的新增共享与等HP剪枝使用可靠分支回复上界；未知分支的无穷界不被旧启发式最小值重新认定为有限。其他已符合上游原版已知来源政策的根保留上游本地/共享行为和回复余量，不把它们称为严格组件证明；未知扩展来源不参与新共享。故障机器人精英曾因本地等HP入口被扩大修改，从上游战损1变成10；v7恢复该非组件路径，8.849秒/战损1/一药，与上游一致。此前v5/v6的单因素范围尝试未恢复战损，全部留档。初版统一禁用未认证根共享，测试体整请求12.856→55.053秒、峰值翻倍，已撤回该扩大范围的变动。
- 无遗物目标的组件证书根，还将剩余必须显式用药次数乘以冻结的初始药水最低成本，加入等HP成本下界。初始槽中的便宜、已消耗或禁用药水仍纳入最小值，只会放松此界；组件生成闭包排除新增药水来源，未知分支保留。魂枢带遗物目标，此项不启用。

- 原有政策、比较规则、总预算及反事实审计保持。有限再生扩展、储君/亡灵新增认证、见证前沿、Fork/布局/容器实验继续保留研究，未纳入本次运行时。
